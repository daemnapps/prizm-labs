## Orchestration
- Claude picks skills by their description; the description list gets ~1% of context, least-used dropped first (code.claude.com/docs/en/skills). Hence: one front-door skill + a searchable library, not 955 installed skills.
- Subagents can preload skills (code.claude.com/docs/en/sub-agents); saved workflows rerun a chain by name (code.claude.com/docs/en/workflows).
- obra/superpowers (307k★, 1.01M installs) auto-chains brainstorm → plan → build → review; BMAD (55k★), Spec Kit (144k★) need typed commands per stage.

## Flags
