# Mobile app with game feel (coins, growth, level-ups, juice)

**Higgsfield first:** website-builder-flow `type: game` builds a playable web game (single or multiplayer) with its whole art pipeline — style formula, autosprite sprite sheets, tiles, Meshy 3D with rigging and 696 animations, Sonilo music, SFX. Use the Expo route below when it must be a native App Store app; the Higgsfield art pipeline still makes every asset.

Ask once: what the app actually does, who it's for, 2–3 games/apps whose feel he wants.

| Stage | Skills to read | Output on the page |
|---|---|---|
| 1. Feel references | Mobbin / Interface In Game / GameUIDatabase screens via browser; Octalysis drives mapped to the app's actions | Reference board + core-loop diagram |
| 2. Core loop + screens | rampstack `onboarding-wizard-design`, `ux-research`; sketch the loop (action → reward → progress) | Screen list + flow → **he picks** |
| 3. Art direction | Higgsfield style sheet (personal Higgsfield workspace), then the full set on that sheet; Kenney.nl (CC0) + game-icons.net (CC BY) as base; `remove_background` | Icon/tile/character sheet → **he picks** |
| 4. App build | expo `building-native-ui`, `expo-native-ui`, `expo-design-system`, `expo-animation` (Reanimated + Skia), haptics + audio | Running app in the iOS Simulator, screenshots |
| 5. Juice | Lottie / Rive celebration moments; sound packs (Kenney audio) | Before/after clips |
| 6. Check | Simulator walkthrough, every screen, both sizes | Screenshot strip |
| 7. Ship | expo `eas-app-stores` / TestFlight → **he says go** | TestFlight link |
