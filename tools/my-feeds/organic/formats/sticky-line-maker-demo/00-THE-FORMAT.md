# Sticky-line maker demo

**146,726,835 views proved it** · 13 of Damon's swipes use this format

## What it is

One text line pinned for the ENTIRE runtime while one continuous handheld demonstration plays out. The line never changes, so nothing competes with the product; the viewer re-reads it while watching hands work. Face is cropped or incidental — the maker is a pair of hands, not a personality.

## Why it works

No cut to a talking head means no permission needed to keep watching. The unchanging line acts as the promise; every second of footage is evidence against it.

## The beats, in order

1. unbox or unwrap the product, hands only, real room — or open straight into use
2. unfold / assemble — the scale reveal
3. place it where it lives (bed, counter, floor)
4. use it as intended, one unbroken take
5. close on the mechanism (switch, controller, texture) — the proof detail

## On-screen text

one line, top third, same words start to finish, casual + an emoji or two; some instances land the line once on the opening beat and drop it, which does not break the format — what matters is that the text never changes and never argues

## Camera

handheld phone, vertical, subject-height, natural window light, no cuts to face

## Higgsfield — image prompt

```
vertical 9:16 photograph, {person} in {plain-clothes} in a real {room}, hands holding {product exactly as described}, {natural light source} from {direction}, phone-camera look, slight grain, no retouching, no on-screen text, face out of frame or cropped above the mouth
```

## Higgsfield — motion

```
handheld follow, subtle breathing movement, no zoom, no ramp — the product stays centred as the hands work
```
