# Concern list with proof photos

**18,159,525 views proved it** · 2 of Damon's swipes use this format

## What it is

The same composite unit repeats at every beat — a fixed frame plus one big label naming a single concern plus a real photo of that exact concern composited into it. The caption changes every cut, the frame does not, and each named thing is paid off by a picture of the actual thing rather than by a claim.

## Why it works

A list makes the viewer wait for their own item to come up, which buys the whole runtime. Each item lands as recognition, not persuasion, because the proof photo is the ordinary unretouched version they already own or already have.

## The beats, in order

1. a quoted grievance or the first named concern opens over the fixed frame
2. concern 2 — new label, new proof photo, identical frame
3. concern 3 — same unit again
4. concern 4 — the list is now clearly longer than the video
5. the close — the answer, or the list simply stops

## On-screen text

one big label per beat naming a single item, in the identical position every time; the label changes on every cut and nothing is ever pinned across beats

## Camera

one unchanging frame or repeated composite unit — the same corridor, the same shelf angle, the same two-shot — reused identically for every item on the list

## Higgsfield — image prompt

```
vertical 9:16, {presenters or setting described exactly} in {one unchanging location}, identical framing every beat, with a white-bordered macro photo of {the named concern described exactly} composited into the lower half, {light source}, phone-camera look, no on-screen text
```

## Higgsfield — motion

```
camera absolutely static and identical at every beat (same seed); only the composited proof photo changes
```
