# Labelled cutaway mechanism

**151,943,666 views proved it** · 3 of Damon's swipes use this format

## What it is

No person, no room, no product in hand — the whole runtime is one unmoving cutaway or cross-section with a fixed grid of labels that never change, and the only thing that animates is the named ingredient travelling below the surface while the named problem resolves. Where live footage is used, the labelled explainer graphic is pasted into the empty part of an otherwise unmoving frame.

## Why it works

You watch the claim happen instead of hearing it. Because the labels never move, the eye has nothing to track except the mechanism, and a mechanism you can see reads as fact rather than marketing.

## The beats, in order

1. the locked cutaway opens with the full label grid already in place
2. the named ingredient is released — liquid crosses the surface
3. it travels down into the structure, still in the same frame
4. the named problem visibly changes state under its own label
5. the resolved state is held in the identical frame

## On-screen text

a fixed headline plus a grid of labels — ingredients on one axis, problems on the other — set on frame one and never changed for the rest of the runtime

## Camera

absolutely locked; a 3D cross-section or a single unmoving real setup, no push, no pan, no cut for the whole runtime
