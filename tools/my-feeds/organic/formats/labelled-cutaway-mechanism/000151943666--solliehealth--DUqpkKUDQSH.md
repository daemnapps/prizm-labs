## Shoot it

**This one cannot honestly be shot on a phone.** It is a rendered animation of a cross-section — a real camera has no angle that shows the inside of a pore, which is the entire mechanic. Rebuild it generated (below), or, if it has to be physical, the nearest version is:

- **Camera** — tripod-locked, dead square-on and level with the subject, macro on a physical cutaway model or prop cut in half so the interior is visible. Zero movement, zero zoom, one take.
- **Light** — flat, even, frontal, no shadow drama. This is a diagram, not a mood piece; the fluid must read clearly against the material.
- **Wardrobe** — none. Nobody is in frame, and nobody should enter. If hands appear, the format has broken.
- **Labels** — added in post as fixed type, placed once and never animated, with thin leader lines to each structure.
