# Pinned-headline monologue

**36,021,647 views proved it** · 13 of Damon's swipes use this format

## What it is

One person, one seat, one room, one unbroken take to camera — and a single headline pinned in the top third that never changes for the entire runtime while rolling speech captions carry the argument underneath. No product, no cutaway, no demonstration, no second location.

## Why it works

The pinned headline is a frame the viewer reads against every sentence spoken, so each line reassigns something under a claim they have already accepted. Nothing changes visually, so the only thing that can hold them is the argument — which is why the headline has to be the strongest line in the piece.

## The beats, in order

1. the headline lands pinned, over the speaker already talking
2. the premise is named — often the audience is addressed directly
3. the argument turns: something familiar is reassigned under the headline
4. the framing tightens or holds; the headline is still there
5. the close — a call to follow, or the headline restated in speech

## On-screen text

one headline in an identical position (often a white box, top third) unchanged from first frame to last, plus burned-in rolling speech captions that change every beat below it

## Camera

one locked or arm's-length frame on the speaker, same seat and same room throughout; no cuts, no cutaway, no second angle

## Higgsfield — image prompt

```
vertical 9:16, {speaker described exactly} in {their own real room or car described exactly}, seated, talking to the lens, {light source}, phone front-camera look, slight grain, no retouching, no on-screen text
```

## Higgsfield — motion

```
camera fixed for the whole runtime, no cuts and no reframe; only the speaker's face and hands move
```
