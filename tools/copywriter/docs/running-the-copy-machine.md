## 2 · Run it

Dry run first, every time — same command with one word on the end. It tells you
whether the brand and product resolve before anything is written.

```bash
python3 machine/copy.py <source> --brand <brand> --product brands/<brand>/products/<product>.md --dry-run
```

The real run:

```bash
python3 machine/copy.py <source> --brand <brand> --product brands/<brand>/products/<product>.md --write-as <formats> --label <name>
```

Pick up where it stopped, without redoing the chain:

```bash
python3 machine/copy.py <source> --brand <brand> --product … --rerun-from stage8
```

Every flag above was confirmed against `--help` at this sha, not the docs (ran).
Leave `--write-as` off and it writes every format in the bank; leave `--label`
off and it names the run for you.

Tests: `python3 machine/test_rollout.py` (docs; tempfile only).
