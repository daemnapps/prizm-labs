# Social copy formats

Every shape this machine writes. **Social copy only** — Damon's ruling
2026-08-25: no advertorials, no listicle pages, no landing pages. Ad copy for
social, and that is the whole scope.

Triage picks one per run. The format binds every stage after it: the same
source, injected the same way, comes out a different object depending on which
of these it is being written as.

| Format | What it is | Length | Form |
|---|---|---|---|
| `short-form` | The punchy one. Scroll-stopper, one idea, out. | **25–60 words** | A few short sentences. Hard first line. No wind-up, no build. |
| `caption` | Meta primary text — the words above the creative in the feed. | **50–120 words** | Real sentences. First line stands alone, then short paragraphs, one idea each, blank line between. |
| `long-form` | A story that earns its length — the middle included, not skipped. | **150–350 words** | Paragraphs. Full prose. A reader who stops for it finishes it. |
| `social-proof` | Built on other people's words — what customers actually said. | **80–200 words** | Quotes on their own lines, connective sentences between them. |

## The rule these lengths exist to enforce

**The source's length is NOT the output's length.** A seven-second video with
five text overlays is not a twelve-word ad. A two-thousand-word blog post is
not a two-thousand-word caption. What transfers from a source is its
*persuasion structure* — where the turn falls, what is withheld, what order
beliefs are dismantled in. What does NOT transfer is how many words the
source's own medium happened to need.

**Fragments are not copy.** On-screen text can be `At 68` on its own because a
face and a beach are carrying the rest of the meaning. In a feed the words are
alone: they have to carry it themselves, in sentences a stranger can read
without the video. If the output could be mistaken for a shot list, a card
stack or a set of overlays, it is not finished copy and it does not ship.

**Add one by adding a row here.** Nothing in the chain hard-codes this list —
triage reads this file, so a new format is a row, not a code change.

## Two rules that ride on format

**Organic source → the creator's voice, never the brand's.** If triage says the
source is organic, the copy is that person speaking. Not brand copy with their
name on it — them. This outranks any house style.

**Already an ad → inherit the structure.** A source that is already direct
response has its commercial structure taken as given; the expansion stage is
skipped. Only an organic source needs that structure built from nothing.
