The one document a media buyer opens. Everything upstream was working
material; this is what leaves the building.

**Written to the buyer, in plain language.** No stage names, no lane codes, no
slot syntax, nothing about how it was made. They need to know what to run and
what to watch, not what the machine did.

Open with what this is, in three lines:

- **What it was built from** — the source, named, and whether it was already
  an ad or an organic post. One line on why that matters here: an organic
  swipe means this reads as the creator, not as us.
- **The format**, in plain words — a caption, a long story, a review — and
  what that means for where it runs.
- **Whose voice it is in.** If it is a named person's, say so plainly and say
  that the copy is written to be read as theirs. This is the single most
  important thing a buyer can get wrong when they edit.

Then:

**THE COPY** — every format that was written, each under its own plain
heading (Caption, Long-form, Review), the full text ready to paste exactly as
it should run, **broken into lines and paragraphs the way it should appear in
the feed**. No brackets, no placeholders, no notes inside the text, and
nothing from the source's own medium — no card numbers, no timestamps, no shot
directions. If any of that appears, it is a defect and it gets reported in the
last section rather than shipped.

Say in one line under each what that version is for.

**THE OPENINGS** — every hook, numbered, each with its one-line intent. State
plainly that these all ship and that picking between them is theirs, not the
machine's. Mark which one is the control — the source's own opening, swiped —
because a buyer testing openings needs to know which is the baseline.

**WHAT TO WATCH** — two or three lines. What this piece is betting on, and the
thing that would tell you early it is not working. Concrete: a hook nobody
reads past, an objection arriving too late, a voice that reads as brand when
it is supposed to read as her.

**THE OFFER, IF IT CARRIES ONE** — price and guarantee, verbatim from the
offer file. If the piece deliberately carries no offer because the format does
not take one, say that explicitly so nobody assumes it was forgotten.

**BEFORE YOU RUN IT** — anything genuinely unresolved: a fact nobody supplied,
a claim standing on contested ground, a collision an earlier stage escalated
rather than decided. Each in one line, with what it would take to settle it.

**Nothing unresolved gets smoothed over.** If a hole survived to here, the
fix is upstream and this document says so plainly — a brief that reads as
finished while resting on a hole is worse than one that admits the hole,
because the first gets trafficked. If there is nothing outstanding, say
"nothing outstanding" rather than omitting the section, so a buyer can tell
the difference between checked and not checked.

Give me the brief.
