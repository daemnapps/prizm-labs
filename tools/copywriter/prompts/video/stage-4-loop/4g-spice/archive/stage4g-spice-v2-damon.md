Print every line of the script in order, exactly as it was handed in — same

nothing cut. After each line, in square brackets, the direction for saying
it:

```
<the line, byte-identical>  [<beat · pause · emphasis · look · where it lands>]
```

What a bracket carries:

- **the beat** — the delivery style and register this line runs in, named
  from the block above, so the reader is never guessing which one applies
- **the pause** — where the silence falls, before or after, and what fills
  it in frame; a pause with nothing happening is dead air
- **the emphasis** — which word in the line takes the weight, if any does
- **the look** — where the eyes go, and when they come back
- **the moment it lands** — what the viewer should have understood by the
  end of this line

Six rules, and the first one outranks the rest:

1. **DIRECTION ONLY, NEVER A CHANGED WORD.** A better word is not this
   pass's to offer. A tightened line, a fixed tense, a dropped filler, a
   swapped contraction — all of them are a rewrite wearing a bracket. If a
   line reads badly, that is a note for the writing stage, not an edit here.
2. **Every line gets a bracket, including the short ones.** A line with no
   direction is a line the performer invents, and an invented read is where
   the register drifts.
3. **The bracket names the dial, not a mood word.** `[deadpan, plain-flat,
   beat-and-pause after "again"]` is a direction. `[natural]` is not.
4. **No line lengths, no seconds, no counts.** A pause is described by what
   fills it, never timed.
5. **An `[UNFILLED]` dial produces no direction for that layer.** Say
   nothing rather than reaching — the performer can read a line straight;
   they cannot unhear a wrong direction.
6. **On-screen text, captions and sound are not directions.** They belong to
   the edit and the brief, and a bracket that carries them ends up baked
   into a take.
