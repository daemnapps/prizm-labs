Choose what this specific source's copy needs to be written well.

The failure this stage exists to end: every video used to get the same four
brand files, so every ad came out generically on-brand — true about the
brand, indifferent to the video. A file that would have changed the copy and
was never opened is the whole problem. So is loading everything, which buries
the two files that mattered under twenty that didn't.

**Choose for THIS concept, not for the brand in general.** The test on every
file is a sentence you can actually finish: *"the copy will be different
because this was read, in this way."* If you cannot finish it, do not select
the file. "It's relevant background" is not finishing it.

Work through the index in this order:

1. **Who is actually in this source.** If the source names a creator, a
   customer, or a person whose profile is in the index, that file is almost
   always a selection — copy written in a specific person's voice without
   reading who they are is the template failure in its purest form.

   **Only that person.** A creator profile for somebody with nothing to do
   with this source is worse than loading nothing: it puts another person's
   habits, phrasing and posting history in front of a stage trying to write
   as *this* speaker, and voice is the thing most easily contaminated. If the
   source's speaker is unnamed, select **no creator profile at all** and say
   so — an unnamed speaker is a fact to respect, not a gap to fill with the
   nearest roster entry.
2. **What the video argues.** Objections it raises or leaves open, proof it
   leans on, the mechanism it claims. Pull the files that hold our real
   answers to those, not our general messaging.
3. **What has already been said.** Any ledger of hooks, angles or verbatims
   already spent. Copy that reuses a spent line is the same ad again with
   new words, and this is the file that prevents it. Select it whenever one
   exists.
4. **What the market around this video looks like.** Competitor teardowns
   and ad matrices, but only when the concept is doing something the
   category also does — a differentiation claim, a mechanism, a price
   argument. Not by default.
5. **Raw evidence** — interviews, tickets, transcripts, focus groups. Big,
   and where real language actually lives.

   **Read the construct's slots before deciding.** If ANY slot calls for a
   customer's own words — a found line, a quoted verdict, testimony, a
   behaviour someone reported — then evidence is **required, not optional**,
   and you select the file most likely to carry that kind of line. A slot
   that needs a real human sentence cannot be filled from an avatar or a
   language bank; those describe how customers speak, they are not customers
   speaking.

   Otherwise, when no slot needs a verbatim, select at most one and only when
   the concept turns on customer phrasing rather than brand assertion.

**Respect what a file says about itself.** The index carries each file's own
`status`, `contested` and `known-issues` lines. A PROVISIONAL or contested
file is still usable — say so in one line when you select it, so the stages
downstream know the ground they are standing on is not settled. A file whose
known-issues describe exactly the claim this video makes is a file to flag
loudly, not to quietly use.

**Never select a file marked NOT LOADABLE.** Name it under what a person has
to do instead, if it matters here.

Keep the total selection under roughly 60,000 characters. If two files cover
the same ground, take the better-sourced one and say why the other lost.

than inventing a reason of substance.

**STANDING TO CARRY FORWARD:**
Anything the copy stages must know about the ground under a selected file —
contested, provisional, a known issue that touches this concept. One line
each, or "nothing contested in this selection".

**WHAT THE DATE MEANS HERE:**
Today's date is at the top. Say in one or two lines whether it constrains
this copy at all — a season the video's wardrobe or setting implies, a
holiday the offer would collide with, a timeline claim that reads differently
in this month than another. If the date genuinely does not bear on this
concept, say exactly that. Do not invent a seasonal angle to have something
to write.
