# The Language Index

Page: (team page) · this file is its Markdown mirror; the page source is `language-index-damon.html` beside it.

When we write copy, it pulls real customer quotes from one engine (`tools/language-layer`). It is fed every morning and reads the brand's quote folders fresh on every pull.

## How it works

- **In:** support tickets, ad comments, surveys and store reviews, interviews and panels, forum research per sub-avatar.
- **Fed (05:30 daily):** new quotes pulled, filed by avatar, sub-avatar and lane, labelled with awareness level.
- **Picked (the engine):** reads every quote folder on each pull, picks what the stage needs, keeps every quote's source.
- **Written:** briefs and video scripts, ad copy and landing pages, emails and calendar, outlier briefs.

## How a pull decides

- **By stage:** each chain step asks for the kind of quote it needs (problem, tried, objection, win).
- **By who she is:** avatar and sub-avatar; face copy pulls face words.
- **By awareness:** unlabelled quotes stay in, ranked just after labelled ones.
- **Fresh first:** never-used quotes first, least-shown before most-shown.
- **Proven words kept in:** up to a quarter of a pull is quotes already used in an asset.
- **Your calls stick:** retired or burned quotes never come back.
