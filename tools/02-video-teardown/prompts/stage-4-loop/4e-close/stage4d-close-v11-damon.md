Finish the ad. Two moves, both short, neither restructuring anything.

**This pass layers. It never rebuilds.** Every beat you did not write this
pass is copied **character for character** from the script so far — same
words, same prices, same timings shifted only by what you insert. You add
at most two beats and move nothing. If a line upstream looks wrong to you,
flag it; correcting it here silently is how two passes end up fighting
over the same script.

**Pre-empt the objection sitting in the script.** Read the script as the
customer, start to finish, and find the flinch — the hesitation the script
creates and never answers. It is nearly always already documented in the
objection bank. The tell is that you feel resistance reading a line and the
script moves straight past it.

Write one line, in the speaker's voice, that kills it. Not a disclaimer, not
a paragraph — one line that sounds like the person talking. Place it
immediately after the beat that raises it; an objection answered three beats
late has already cost the click. If the script raises more than one, handle
the one that stops the most people and list the rest in the flags.

**Name the flinch before the offer.** The objection line is written at the
moment of the viewer's flinch — the hesitation they just felt, named aloud in
their own words as the objection bank records them. The guarantee-led close
answers that exact hesitation. The offer block drops the ambience and holds
the voice clear — never fake scarcity (the never-pair rules below still
hold). A close that answers a different objection than the one the viewer
flinched at is a close that was written for someone else.

**Redefine the objection the bank names.** An objection is often not argued
away, it is renamed — and the bank says which one is live here. Three shapes,
matched to what the objection actually is: *too complicated* is answered by
relabelling the process in ordinary words the avatar already uses; *too small
a thing to bother with* is answered by connecting it to the larger outcome it
sits inside, or by showing it is constant rather than occasional; *too
expensive* is answered by changing what the price is compared against, never
by defending the number. Name which one you used and quote the bank row it
answers. A redefinition with no bank row behind it is a reframe of an
objection nobody raised.

**Close with the offer — through the source's ending, not over it.** Check
the replication spec before touching the final beat. **If the spec marks
the source's ending device fixed or load-bearing, that device stays.** An
engagement ending the format depends on is part of why the video worked;
killing it is restructuring, and the previous version's instruction to do
so was wrong. Instead, the offer arrives as a **continuation the device
hands into**: the source asks its question, and the speaker answers it
themselves — what they ended up doing — and the offer lives inside that answer.
The engagement bait fires, then the sale lands.

Only when the spec does not protect the ending — the source just trails
off, or its CTA is platform housekeeping with no structural job — do you
replace it outright with the offer.

Either way the offer itself comes from the offer file: price, what is
included, the guarantee, the ask.

**A rule in a supplied file is not negotiable.** If the offer file forbids
something, remove it and report the removal. Never keep a known violation
and defer the decision into a flag, and never argue that it is acceptable
under some condition. Flags are for things you cannot resolve — a named rule
is not one of them.

**An upstream `[SLOT: …]` is still empty**, whatever the prose around it
says. If an earlier pass named an example figure in its commentary, that
figure does not exist. Carry the slot forward unfilled.

Four rules on the offer, all hard. The guarantee carries the risk, not
urgency. Quote the guarantee exactly as the offer file records it — never
paraphrase, soften or strengthen it. Obey every never-pair rule that file
sets. And never state a price it does not confirm; if the brand sells at
more than one price, say which one this is.

Keep the close to the length the format can carry. A close that runs longer
than the beat before it reads as a different video.

There is an optional move, and it is not part of every pass. **Restructure
who speaks** when the asset would be materially stronger with a different
narrator, or when geography is a targeting advantage the supplied files
support. Keep the source format's best device when you do — the narrator
changes, the thing that made the format work does not. Produce it as a
separate variation rather than an edit, so both survive and can be tested
against each other.

**The variation obeys every rule the main script obeys** — same claim
limits, same never-pair rules, same ban on invented numbers and
unsubstantiated results. A variation written outside the rules is not a
variation, it is a second problem.

Give me these eight sections.

**1. THE OBJECTION LINE**

The flinch, quoted from the script · the objection it maps to in the bank ·
the line, in voice · where it goes.

**2. PROOF PLACEMENT**

Proof lands where the reader already demands it, not where it is convenient
to put it. Read the script start to finish and name the beat where doubt
peaks — the moment the viewer is most likely to stop believing. Then name the
proof that lands there, from the supplied files only: a stat, a test, a
testimonial, an authority, a visible result. Quote it, and say which beat it
sits in.

Proof front-loaded because it is proof is proof spent before it was wanted.
And proof copy is still selling copy — short, specific, dramatic. A dry fact
in the middle of a script in voice is a seam the viewer hears.

If the files carry no proof for the beat where doubt peaks, write
`[SLOT: proof at the doubt beat]` and say what kind of proof would fill it.
Never invent one, and never promote a claim to a proof by restating it.

**3. THE ANCHOR**

**A price is never stated bare.** Name the anchor this price is set against —
what the viewer would otherwise be spending, over what period, on what — and
write the comparison as one line in voice. The anchor comes from the offer
file or the product file; if neither carries one, write
`[SLOT: price anchor]` and leave the price un-anchored rather than inventing
a comparison. Never anchor against a competitor's price unless a supplied
file states it.

A price cut needs its own reason to be believed. If the offer file carries a
discount, name the believable reason it is cheap, from the file. A discount
with no reason behind it reads as the product being worth less.

**4. THE GUARANTEE**

The guarantee is the last intensification beat, not a legal footnote:
**every promise the script made, restated once more, wrapped inside the risk
reversal.** List the promises the script made, in order, then write the
guarantee beat that carries them — with the guarantee sentence itself quoted
exactly as the offer file records it, never paraphrased, softened or
strengthened. The promises are restated around that sentence; the sentence
itself is untouched.

If the offer file records no guarantee, say so plainly and write no
substitute. An invented guarantee is the most expensive line in the chain.

**THE SUPPLY MATH — the guarantee becomes an instruction.** Work out, from
the offer and product files only, what the offer physically gives the buyer
and how long it lasts: units in the offer × amount per unit ÷ (amount per use
× uses per week) = how long the supply runs. Set that against the guarantee's
window. **The whole offer is used inside the guarantee window**: when the offer
file rules the routine that does that (how often, how much each time), use it
word for word; otherwise work it out — offer ÷ uses in the window = amount each
time — and print it. Then write the guarantee beat as **exactly what the buyer does**: how
often, for how long, with how much of what they bought — so the viewer hears
the routine that the guarantee covers, and the offer's size answers "will it
last". The guarantee sentence itself is still quoted exactly. Print the math
in one line, each figure with its file. A figure the files do not carry is
written `[RESEARCH: what is needed]` — the machine researches it after this
pass — and never estimated.

**5. THE CLOSE**

Whether the spec protects the ending device, in one line. Then the offer,
written — as a continuation of the device if protected, as a replacement if
not.

**THE ASK IS THE CLICK.** This is an ad, whatever the source was. The last
thing said, and the last thing on screen, asks the viewer to tap the button
and buy — the platform's own button, in words the offer file allows (where the
file says no link, the button carries the click and nothing names a URL). The
source's engagement device may still fire before it — a comment ask earlier in
the video is a good re-hook, especially in a story or a creator-style piece —
but a comment ask, a follow ask or an opinion ask is never the last ask.

**No timecodes in this section.** The words and the staging only. THE FULL
SCRIPT is the one place a beat gets a time, because a brief that reaches a shoot
carrying two timelines for the same beat is a hazard that surfaces on the
day, and the maker has no way to tell which one is real.

**6. THE FULL SCRIPT**

Hook to close, beat by beat, each marked `[SOURCE]` or `[ADDED]`, with the
scene per beat. Every beat this pass did not add must match the script so
far exactly.

End with one line: the source's runtime, the runtime the placement plan
expected, and where this script actually lands — three numbers, nothing
else.

**If your total is past the plan's expected runtime, say so in FLAGS and
say by how much.** Do not quietly trim beats to hit the number and do not
pretend the number was met. A format that ran forty seconds does not
survive being briefed at ninety, and the maker is the one who finds that
out on set — so the overshoot is the finding, and a human decides whether
to cut a move or accept the longer cut.

**7. FLAGS**

Every rule in the product or offer file this script brushes against, every
claim without substantiation, every unfilled slot, every objection left
unhandled, every upstream line you believe is wrong. Never invent a number
to close a gap.

**8. VARIATION**

If the optional move was used, the alternate version, kept whole and
separate.

## THE VIBE HOLDS

This is social media. We are technically making an ad, but it has to live in
the feed as content, and the source earned its numbers partly on how it
feels. The doctrine read above names that feel: its `HUMOR`, `DELIVERY
STYLE`, `REGISTER`, `PACING`, `REFERENCE WORLD` and `AVOID` lines.

Print, before anything else you write:

`THE VIBE: <one line — how the source feels to watch: funny or straight, and
in which register; the world it leans on; what it never does>`

Then hold it in every line you write:

1. **A funny source stays funny.** Where the source jokes, what you write
   keeps joking in the same register — new lines included. Humor stays out of
   the proof and the offer beats only where the source itself played those
   straight.
2. **A straight source stays straight.** Never add a joke the source did not
   make.
3. **Every new line sounds like it came from the same video**: the same
   speaker's voice, the same reference world, nothing from the `AVOID` line.
   A line that reads like an ad dropped into the video is a defect, however
   true it is.
4. If the doctrine read says `not shown in the record` for a line, hold what
   the source's own transcript does.

**Feel versus structure.** Some `AVOID` lines are about feel (a too-clean
look, stacked superlatives, ad-voice, a sell in the opening seconds) and some
are about structure (no price, no proof beat, no mechanism, no offer). Feel
always holds. Structure gives way to the sections line: on a Variation video
run, a section the branch's sections line adds is written — in the source's
feel — even where the source avoided it. A price is still bound by the target
level's must-not.

**The mood and the one-of-a-kind line hold too.** The doctrine read's `MOOD:`
(the rhythm and where it shifts) and `WHAT MAKES IT UNIQUE:` (the combination
worth banking) are part of the feel: new lines keep the mood's rhythm, and the
unique combination is never smoothed away.
