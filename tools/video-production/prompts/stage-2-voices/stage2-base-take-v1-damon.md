# Stage 2 · Base take — v1

Creates a voice from nothing. The paragraph IS the voice — every attribute
steers it. Run once per character; every later line clones this take.

---

[PERSONA — age, accent, vocal texture, temperament, how they speak],
speaking slowly and steadily. [He/She] says: [THE LINE, written the way it
should be performed — punctuation is pacing]

---

Settings that hold: speaking rate below neutral (slower reads win),
moderate expressiveness. A real uploaded recording also works as the seed
voice instead of this prompt.
