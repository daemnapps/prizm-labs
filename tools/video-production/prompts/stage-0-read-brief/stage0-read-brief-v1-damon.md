# Stage 0 · Read the brief

**Mechanical. No model, no judgement, no summarising.**

This stage exists because of what happened without it. The plan for
`ser-01-stress-showing` was assembled from two earlier working files — a
consolidated talking spine and an old storyboard's insert rows — and the
brief's own **WHAT TO GENERATE** section was never opened. The result: six
openings, three offer cards, a bathroom, a manufacturing floor and a
before-and-after were not deferred or rejected. They were never seen. Nothing
compared the plan to the brief, so nothing reported them missing.

## The rule

**Every item the brief asks for enters the plan. All of them. Now.**

Not the ones that seem important, not the ones that fit the runtime, not the
ones a previous working file happened to carry. If the brief writes it, it
becomes a row with an id and a state of `not built`.

A row may later be **dropped** — but only out loud, in the plan, with a
written reason, and it still shows on the board as a gap against the brief.
Silence is the failure this stage prevents.

## What it extracts

| from the brief | becomes |
|---|---|
| `**Opening N · <name>**` with its `Film:` and `Say:` | an opening row |
| `TYPE A` scenes | talking beats |
| `TYPE B` scenes and their `Happens:` | cutaway rows |
| `TYPE C` scenes and their `Product:` / `On screen:` | offer-card rows |
| `## THE CAST` | the cast the shots must attach |
| `## THE WORLD` | every world named — each one is a set that has to exist |
| `## THE PRODUCT` | which product elements are load-bearing |

## Consolidation is an override, not a deletion

Where a run departs from the brief's structure — thirty-three short scenes
becoming eight continuous takes — that is written to `plan.overrides` with the
ruling, the date and the reason, and the board shows **brief → agreed** with
the reason underneath. A departure you decided is a decision. A departure
nobody wrote down is indistinguishable from a mistake, and on this run it was
one.
