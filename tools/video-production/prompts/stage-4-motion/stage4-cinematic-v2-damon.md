# Stage 4 · Cinematic shot — v2

*v2 (2026-09-17): the no-cut line, verbatim, added to the shape — every
video prompt this machine ships carries it, without exception (the course
write-up, Damon 09-14, §7).*

Prompted drama shot. 0–2 references + a written direction; the model
generates its own ambience. 8–15s single takes. Works with no image at all
for establishing shots.

**Every example in this prompt is illustrative only.**

---

Cinematic drama, [SETTING + LIGHT]. [The character from the first reference
image] [ONE physical action, described beat by beat]. [The emotional
reaction, in one sentence]. [SOUND — what is heard, and what is NOT: no
music / no dialogue / room tone only]. Single continuous take, no cuts or
scene changes.
