# Stage 1 · Character sheet — v2

*v2 (2026-09-17): one rule block at the top — a person who is visible in source footage is cloned from a source frame, never rebuilt from words. The sheet composition below is unchanged from v1. No new variables.*

## Before writing a word: is this person already on film?

**A person visible in the source footage is CLONED, not described.** Pull
the cleanest source frame — sharp, front-on, well lit, the face unobscured
— upload it, and generate the sheet with that frame as the **only**
reference. The text below is the fallback in that case, not the
instruction: it fills in what the frame cannot show (the back, the full
body) and nothing more. A character rebuilt from a description of the
source is a different person who matches the description; the source
frame is the person.

Text-from-description — the sheet below, filled from the [SLOTS] — is the
default **only when no source exists**: a character the brief invents, or
one the source never shows.

Record which route was taken, and the source frame id when it was a clone,
beside the sheet in the character's folder, so the next format that uses
this person does not have to rediscover it.
