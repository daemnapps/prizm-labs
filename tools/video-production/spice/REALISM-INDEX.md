# The realism index

Human-level realism, by format and by stage. The machine reads `realism-index.json`; this page is the same list for people.
Part of video spice (`../VIDEO-SPICE.md`). the owner, 2026-10-20: *"subtle selfie hand holding being slightly shaky … realistic movements, human level … it all depends on the format"* and *"some things will be editing and some things will be production … some things might be even at the writing stage."*

| Stage | Who does it |
|---|---|
| **writing** | the production brief decides it: which beat, which line, which shot |
| **production** | the picture or the clip carries it (its prompt words) |
| **editing** | the editor adds it (tools/video-edit) |

## Formats

| format | what it is |
|---|---|
| `selfie-talk` | one person, phone at arm's length |
| `propped-phone-talk` | one person, phone propped on a stand or object |
| `counter-demo` | a person making or showing something at a counter or table |
| `walk-and-talk` | filming while walking |
| `sit-down-interview` | seated, phone on a stand facing them |
| `street-interview` | an interviewer's phone held out to a stranger |
| `grwm-mirror` | getting ready, often in a mirror |
| `pov-hands` | the phone looking down at the person's own hands |
