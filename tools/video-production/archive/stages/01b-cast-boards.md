# Cast boards — the workflow, and every prompt verbatim

The flow (BOARD-SPEC, the owner's step-back ruling 2026-08-31):

```
UNDERSTAND the baseline (principles, human eyes only — never an input)
   ↓
PLAN — each character's own board plan, written before pixels
   ↓
GENERATE — one board at a time; inputs are ONLY:
   the character's canonical master (the one identity image, ever)
   + their identity block + their plan
   ↓
QC — every board before the next: right person in every panel,
   exact panel count, exact age, no readable text, no artifacts
   ↓
BANK — pixels to Drive + disk; character.md records the set
```

Model: Seedream 4.5 edit (per the model role map). ~$__ per board.

Below: the EXACT prompt each generation sends — assembled live from the
board templates + each character's identity block + their plan. Change a
plan or an identity block and these prompts change with it; this page is
regenerated by `boards.py --dry-run`.
