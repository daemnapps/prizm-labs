# Format · demonstration

**Shape.** The product doing the work. Hands, surfaces, before and after.
Little or no face, and often no dialogue at all.

| | |
|---|---|
| **Cast** | Often none by name. Where hands or a forearm appear, they are still a trained identity — hands age, and mismatched hands break a piece as fast as mismatched faces. |
| **Places** | One surface or one small space, usually. |
| **Scenes** | One scene per action; an action is one beat and the scene is as long as the action takes to land. Length is never a number here. |
| **Sound** | Texture and room tone; voice-over added at the edit, or generated as narration. |

**What a scene contains.** The product doing the work — hands, surfaces,
before and after; an action is one beat.

**The beat shape.** Before (the problem, shown) → the product arrives →
the action, one beat per mechanic → after (the same framing as before) →
offer. Before-and-after needs the *same* framing on both sides or the
comparison reads as a trick — write the framing once and use it twice.

**Stations used.** still · motion · audio (texture, room tone). Cast only
when hands are in frame. Voice only if narration is generated rather than
added at the edit.

**The references it needs.** The packshot in every frame the product is in
— and it is in nearly every frame. The hands' identity reference where
hands appear. A texture reference where the product's texture is the
point.

**The sections that carry the weight.** 09 dynamic description and the
product locks. This format lives or dies on the mechanics being written as
**separate beats** — "squeeze onto the forearm → set the container down →
rub in small circles" — because a model glues actions together and welds
the object to the hand.

**Ledgers that apply.** Object (which is the whole piece here),
atmosphere, camera. Wardrobe only where sleeves are in frame.

**Post (edit-time).** The voice-over, captions, before/after labels, the
music.

**Gates it adds.** None — `RUN-PROTOCOL.md` carries them.

**The failure this format invites.** The label. This is the format where
the product is largest in frame and most often wrong. The packshot
reference carries it in-scene; where the label fills the frame, composite
the real packshot rather than generating it. The second failure is hands
gripping the product — one re-prompt, then the product on the surface and
the hands out of frame.

**The run it was proven on.** Not yet run end to end on this machine.

**What still fails.** Unknown until a run is filed.
