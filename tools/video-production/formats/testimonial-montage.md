# Format · testimonial montage

**Shape.** Several different people, one line each, cut together. No
shared space, no story — the accumulation is the argument.

| | |
|---|---|
| **Cast** | Many roles, each appearing once or twice. Every face trained, because a face that appears twice must be the same face both times. |
| **Places** | One per person, all different. Difference is the point. |
| **Scenes** | One line per scene, one scene per voice; a scene is as long as its line. Length is never a number here. |
| **Sound** | Many voices. They must be distinct from each other — write that lock explicitly. |

**What a scene contains.** One person, one line, one room, many times
over — the accumulation is the argument.

**The beat shape.** The strongest line first → the lines, each a different
person, ordered so the claim widens (different ages, rooms, energies) →
the product, once, near the end → offer. It never slows; the rhythm is
the piece.

**Stations used.** cast (every face) · still · motion · voice (one per
person, distinct). No restyle, no audio station.

**The references it needs.** Each person's cast sheet in their own frames.
The packshot in the one frame the product appears in.

**The sections that carry the weight.** 04 the grade — it is the *only*
thing tying unrelated people and rooms into one piece — and 05
performance, so the voices differ.

**Ledgers that apply.** Wardrobe (per person) and atmosphere (the shared
look). **Not** entrance, position or camera — there is no continuous space
to protect.

**Post (edit-time).** Captions (often the name and a word under each
person), the music, the cut rhythm.

**Gates it adds.** None — `RUN-PROTOCOL.md` carries them.

**The failure this format invites.** Everyone starting to look like the
same person, or every room looking like the same room, because a single
prompt template is being reused with only the words changed. Vary the
place, the light and the framing deliberately; keep only the grade
constant. Cast for genuine variety — age, build, room, energy — and write
it into the production document as a spread, or the model returns a set
of near-identical people. This is the one format where identity training
is protecting *difference* as much as sameness.

**The run it was proven on.** Not yet run end to end on this machine.

**What still fails.** Unknown until a run is filed.
