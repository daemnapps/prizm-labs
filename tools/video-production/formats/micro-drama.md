# Format · micro-drama

**Shape.** Several characters in one continuous space, a confrontation
built on a misunderstanding, a turn where the truth lands, and an offer at
the end. The format this method was first proven on.

| | |
|---|---|
| **Cast** | Three to four roles — `{LEAD}`, `{FOIL}`, `{WITNESS}`, `{AUTHORITY}`. Every face trained. |
| **Places** | ONE continuous set for the whole piece. The single hardest constraint and the reason the ledgers exist. |
| **Scenes** | One scene per exchange; length is driven by the dialogue, not the action, and a scene runs until its line has landed. Length is never a number here. |
| **Sound** | Dialogue throughout, generated in the same pass as the picture. |

**What a scene contains.** Several characters in one continuous set — a
confrontation, a turn, an offer.

**The beat shape.** Open on the misunderstanding (or an alternate,
mystery-first opening as its own scene) → the confrontation escalates →
the turn: the truth lands → the proof beat, generated long → the offer,
which is a block, not a beat.

**Stations used.** cast (every role) · still · motion · voice. No restyle
unless the piece is stylized; no audio station.

**The references it needs.** Every character's cast sheet in every frame
they are in, in the same order every scene. The set's plate. The packshot
in the proof beat.

**The sections that carry the weight.** 06 wardrobe locks, 07 blocking,
08 scene setup with coordinates. Multiple people in one room is exactly
where staging invents itself.

**Ledgers that apply.** All six, and the entrance ledger is the one that
saves the piece: a character enters once in a piece, ever.

**Post (edit-time).** Captions and the music. The continuity is in the
generation, not the edit — the edit's job is to match the incoming scene's
first frame to the outgoing scene's last.

**Gates it adds.** None — `RUN-PROTOCOL.md` carries them.

**The failure this format invites.** A character entering twice, or
appearing on the wrong side of the frame between scenes. Coordinates in
section 08 and the entrance ledger in section 07 are the fix; catch what
survives at the cut.

**The run it was proven on.** The method was proven on this shape
(2026-09-01, the production the method docs were written from); no piece
has run this machine's route end to end.

**What still fails.** Unknown until a run is filed under the protocol.
