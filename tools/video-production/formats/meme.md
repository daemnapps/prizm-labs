# Format · meme

> **DRAFT, 2026-09-17 — written from the 16 Sep session's reports, not from
> a run record.** Meme-style pieces ran on Higgsfield that day (the
> collar-pull slap; one man across sprint, code, pole, sand and tablet
> beats) but their records lived in the chat sandbox, so every line below
> is what the reports let us infer. Damon corrects; the first run filed
> under `runs/video-machine/` replaces the inference with evidence.

**Shape.** A swiped meme, re-made. The source's structure is the whole
format: the scroll-stopper — one decisive physical action — and the beats
that follow it, with the brand's line laid on top at the edit. The
pictures carry the joke; the words are a caption, not a script.

| | |
|---|---|
| **Cast** | One, `{LEAD}` — the "dude". One trained identity, in every beat, because a meme cuts fast and a different face in beat four is the first thing a viewer sees. A second person only if the source has one. |
| **Places** | Several, one per beat, as the source has them. No continuous set. |
| **Scenes** | One scene per beat, driven by the beat, never by a line — there are no lines. A beat is as long as its punch takes. Length is never a number here. |
| **Sound** | Usually none generated. The source's sound design, or music, at the edit. A spoken beat is the exception and is written as one. |

**What a scene contains.** One swiped meme beat — the source's decisive
action kept unchanged; the caption added at the edit.

**The beat shape.** The scroll-stopper first (the slap, the reveal, the
flip, the drop) → the escalation beats, each one action → the payoff →
the product or the line as the last caption. It never slows down; a meme
that slows is a different format.

**Stations used.** cast (once) · still · motion. No voice, no restyle
unless the source's look is the joke, no audio.

**The references it needs.** The cast sheet in every frame that shows the
lead. The source video's cleanest frame for the scroll-stopper — the
action is copied from it, not described. The packshot if the product is
ever in frame (it usually is not; the product is the caption).

**The sections that carry the weight.** 09 dynamic description — one
action per beat, written as a chain — and the source-action line. Sections
1–8 are near-boilerplate here.

**Ledgers that apply.** Wardrobe (the lead, whole piece — a meme cut
across places betrays an outfit change instantly). **Not** entrance,
position, object or camera — no continuous space.

**Post (edit-time).** The captions — all the words — and the music. The
machine never generates a caption; the plate stays clean so one set of
beats carries every caption variation.

**Gates it adds.** None — `RUN-PROTOCOL.md` carries them. The QC gate's
**source action parity** check is what protects this format: the
decisive action must survive unchanged.

**The failure this format invites.** The scroll-stopper softened. On 16
Sep the source's collar-pull slap tripped a filter and came back as an
arm-block — a piece with the joke removed. The fix is the framing, never
the action: played for laughs, no injury, everyone fine; then a different
model; never a softer verb. The second failure is the lead drifting into
a different man across the beats — five of eleven clips on 16 Sep — which
the verify gate now stops before motion.

**The run it was proven on.** Ran 2026-09-16 on Higgsfield; no run record
in the repo. Not yet run under the protocol.

**What still fails.** Unknown until a run is filed. Expect: the filter on
physical-comedy actions, and hands in close action beats.
