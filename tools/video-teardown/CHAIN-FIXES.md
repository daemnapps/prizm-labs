# Chain fixes — what stops a swipe from being ruined (24 Sep 2026)

The game (the owner): **swipe → get clear on what works and why → expand where it's
needed → spice so it's smooth.** Every fix below exists because a real run broke
that. Brand- and product-agnostic: nothing here names a brand; each run reads its
own brand's files.

Target: batch 5 swipes a day end to end, then more.
