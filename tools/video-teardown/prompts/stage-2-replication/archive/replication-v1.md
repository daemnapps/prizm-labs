Here is a complete teardown of a video asset: {teardown_record}

Turn it into a replication spec: the discrete, reusable elements that make
this asset work, abstracted from its brand, product and subject so it can
be executed for any brand in any category.

Two rules govern everything below:

**Abstract, never copy.** No mandate may carry the source's brand, product,
or subject. Convert every specific into its generic function — "positions
itself against a category-leading incumbent the audience already trusts,"
not the incumbent's name.

**Every element is discrete and injectable.** One element is one thing to
build. Each one names where a new brand's material enters.

Give me these six sections.

**1. FORMAT**

What kind of asset this is, in one line.

**2. THE STRUCTURAL SKELETON**

A table: `Phase | Function | Duration (seconds) | % of runtime | Fixed
position?`

Give duration both absolute and proportional so the format can be rebuilt
at any length. State whether each phase must stay in this order.

**3. THE ELEMENT INVENTORY**

The core section. Number every discrete element. For each, give all four
of these as separate labeled lines:

- **ELEMENT** — a name for the thing.
- **MANDATE** — what must be true. Written generically, executable without
  a judgment call, numbers where numbers apply. No brand, product, or
  subject from the source.
- **SOURCE INSTANCE** — how the reference did it, quoted exactly, so the
  standard is visible.
- **INJECTION SLOT** — what brand-side material fills this: customer
  language, product truth, the offer, identity/character, or FIXED if the
  element is structural and nothing gets injected.

**4. THE SCRIPT ARCHITECTURE**

The script as a slot-based template, beat by beat. Write each beat as a
fill-in line with its slots marked in brackets — for example: "If you
[SPECIFIC BEHAVIOUR THE CUSTOMER RECOGNISES], do not [ACTION] because
[REVERSE-PSYCHOLOGY REASON]." Under each beat, state its job in one line
and quote the source's version.

**5. LOAD-BEARING**

The elements that carry the performance — change them and the asset stops
working. One line of why for each.

**6. SWAPPABLE**

The elements that can change freely per brand at no cost. One line of why
for each.

Output rules: mandates only, no principles and no "consider." Leave out
anything that does not control this format. Never name the source's brand
or product in a mandate. Say nothing about how the asset gets produced —
the same spec must be executable as a generated video, a creator shoot, or
a studio shoot.
