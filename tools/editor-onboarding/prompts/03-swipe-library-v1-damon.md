# Swipe library — v1

*Paste this in Higgsfield Supercomputer when you want to see what has been
swiped for a brand, or find something to rebuild. Replace `{BRAND}`.*

*v1 (2026-09-22): first version.*

---

```prompt
Open the swipe library for {BRAND}.

1. In Google Drive, open `SWIPE LIBRARY.md` at the root of the shared drive. Read it live. Show me the top table — what exists and how much — in four lines.

2. Show me every feed whose name starts with `{BRAND}--`: the feed, how many posts are kept, how many are entertainment and how many educational, and when it was last refreshed. A feed is one customer type's scroll — what that person watches for free, not our product.

3. I pick a feed. Open its `FEED.md` and show me the first thirty rows as a table: lane · platform · author · what it is · link. Entertainment first. If I ask for the educational lane, show that instead.

4. I pick a post. Open its link so I can watch it. Then tell me, in three lines, what its structure is — the hook, the middle, the close — using only what is on screen. Do not invent what you cannot see.

5. If I say "tear it down", run the video teardown from tools/video-teardown on that post for {BRAND}, exactly as HOW-TO-RUN-IT.md describes, and put the brief in the brand's `briefs/` folder so it shows on the queue.

Also available, when I ask:
- "show me the formats" — the organic formats in tools/my-feeds/organic/formats/, one line each: the name and what carries the value.
- "show me the angle shapes" — the paid angle shapes in tools/my-feeds/paid/angle-shapes/, one line each.
- "show me the swipe videos for <format>" — the codes under that format in SWIPE LIBRARY.md; each code is a folder on the drive with `video.mp4`, the rebuild sheet `handoff.md`, and the beat strip `sheet.jpg`.

Rules: never invent a post, a number or a structure. If a file cannot be reached, say which one, in one line.
```
