# How it works — the shot list

Short screen recordings for [daemn.co/how-it-works.html](https://daemn.co/how-it-works.html).
One shot per section of the page, in the page's order. Each one is a single
take, under two minutes, recorded inside Higgsfield Supercomputer or Claude
Code with the repo cloned and a brand folder connected. Talk to the person
who will make the ads.

Rules for every shot: no ad-account or ad ids on screen, no spend, no
customer names, no creator names. Roles, not people. If a screen would show
one of those, move the window or record the brand template instead.

|---|---|---|---|---|

## Where the recordings go

Each finished recording is named `how-it-works-NN-<section>.mp4` (the row
number, then the section in lower case) and goes to the onboarding folder
on the shared drive, next to the walkthrough video. The page links to them
once they exist; until then the page stands on its own.
