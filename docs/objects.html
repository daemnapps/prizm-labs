Prizm · the object library

Objects.

The things the brand is made of. One white beam goes into the glass and a spectrum comes out — so the hero object is the prism itself, and everything else is chrome caught in the same light.

Each one is shot the same way: one object, three-quarter view, hard key from upper right, a real contact shadow, bone ground, nothing else in frame. That consistency is what makes them a set rather than eight pictures. Here they are live: scroll, and watch the light move across them.

How to use them

Rules, so the set stays a set.

  • One object per surface. Two in one frame reads as a product shot, not a brand.
  • Never on white. They are lit for bone; on white the contact shadow disappears and they float wrongly.
  • Never recoloured. Chrome takes its colour from what is around it. Put the spectrum near it instead — a prism hairline, a hued card edge.
  • Scale is free. Impossibly large beside type is the surreal half of the system doing its job. Impossibly small is just a bullet point.
  • The shadow stays. It is the only shadow on a page, and it is what makes the object real rather than pasted.
  • A new object earns its place by standing for something no existing one does — then it gets shot the same way: one object, three-quarter view, hard key upper right, bone ground.
Full-resolution originals are kept out of this repo — it is a toolkit, not an asset library. The 900px WebPs here are the web set.
