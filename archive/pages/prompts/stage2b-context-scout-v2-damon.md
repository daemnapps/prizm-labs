Choose what this specific page's copy needs to be written well.

The failure this stage exists to end: every run used to get the same four brand files, so every page came out generically on-brand — true about the brand, indifferent to the construct. A file that would have changed the copy and was never opened is the whole problem. So is loading everything, which buries the two files that mattered under twenty that didn't.

**Choose for THIS construct, not for the brand in general.** The test on every file is a sentence you can actually finish: *"the page will be different because this was read, in this way."* If you cannot finish it, do not select the file. "It's relevant background" is not finishing it.

Work through the index in this order:

1. **Whose voice the page is in.** Triage bound the narrator to a kind of person in our avatar's register. If a cast persona or a sub-avatar card matches that person, it is a selection. Never a real customer's profile as the narrator — a real customer may be quoted, never impersonated.
2. **What the construct argues.** Objections it raises or leaves open, proof it leans on, the mechanism it claims, the comparison it makes. Pull the files that hold our real answers to those — the product card for the mechanism and the sanctioned ingredient phrasing, the objection bank for the flinch, the offer file for every figure.
3. **What this brand has already claimed in public.** The live pages, the running ads — so the page does not contradict them, and so the control's own lines are known.
4. **What the market around this page looks like.** Competitor teardowns, only when the construct compares, ranks or prices against the category. Not by default.
5. **Raw evidence** — interviews, tickets, panels. **Read the construct's slots before deciding.** If ANY slot calls for a customer's own words — a found line, a quoted verdict, a review — evidence is **required, not optional**, and you select the file most likely to carry that kind of line. A slot that needs a real human sentence cannot be filled from an avatar card; cards describe how customers speak, they are not customers speaking.
6. **The questions Schwartz says to ask.** Read the list above. Where the brand holds a file that would answer one of them for this avatar — which desire leads, which awareness rung, what the category has already claimed — select it, even if nothing else on this list would have caught it.

**Respect what a file says about itself.** The index carries each file's own `status`, `contested` and `known-issues` lines. A PROVISIONAL or contested file is still usable — say so in one line when you select it. A file whose known-issues describe exactly the claim this page makes is a file to flag loudly, not to quietly use.

**Never select a file marked NOT LOADABLE.** Name it under what a person has to do instead, if it matters here.

Keep the total selection under roughly 60,000 characters. If two files cover the same ground, take the better-sourced one and say why the other lost.
