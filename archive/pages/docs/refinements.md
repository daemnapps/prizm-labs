# Workflow refinements — the page machine

The running log of what got in the way, run by run, so the chain gets faster
next time. Opened 2026-09-17 on Damon's call: run the Sellmore CPK body-scrub
pages through the chain for the face scrub, note every issue as it happens,
and feed this document back in to fix stages.

Format: one row per issue — where in the chain it bit, what happened, what it
cost, the fix proposed, and whether the fix has landed. Rows are never
deleted; a fixed row says so.
