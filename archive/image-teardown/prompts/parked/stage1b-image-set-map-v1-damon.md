You are looking at a SET of static image ads that are variations on one
proven concept, from one advertiser, running at the same time. They are
numbered IMAGE 1, IMAGE 2, IMAGE 3 in the order supplied.

Your job is the **iteration map**: what is held constant across the set, what
is varied, and on which axis each variation moves. This is not a teardown of
any one ad — each ad has its own teardown already. This is the record of the
set as a system.

The whole value of this output lives in one distinction, so keep it clean:
**the constant is the concept; the variable is the change surface.** An
element in the wrong column corrupts every brief built downstream.

Same three laws as the single-ad teardown:

**Accuracy law.** Never guess. If you cannot resolve something clearly, write
`[UNCLEAR: …]`. Mark inferences `(inferred)`. Quote every piece of copy
exactly as set — a paraphrase in this document is a defect, because the whole
point is which words changed.

**Consistency law.** Refer to the ads only as IMAGE 1, IMAGE 2, IMAGE 3.
Every element gets ONE name, used identically everywhere.

**Depth law.** A difference is not "the layout is different." A difference is
the specific element, its value in each ad, and the axis it moved on. If
length becomes a pressure, cut nothing — write longer.

**This is observation, not evaluation.** Do not say which ad is better, do
not recommend, do not predict performance. You have no performance data. If
you find yourself ranking, stop and record the difference instead.

I need six things.

**1. THE SET AT A GLANCE**

One table, one row per image:

`Image | Aspect ratio | Treatment | Headline (verbatim) | Offer block present? | Distinct or duplicate?`

In the last column say plainly whether this ad is a genuinely distinct
execution or the same execution re-cut for another placement — and name the
evidence.

**2. THE CONSTANT — what every ad in the set holds**

The concept, itemised. For each constant: name it, quote or describe its
value, and confirm it appears in all three. Cover at minimum: the core claim,
the subject and who they are being, the setting, the props, the product
mechanism shown, and any phrase that appears word-for-word in more than one
ad. Quote every repeated phrase exactly, and say which images carry it.

This section is the answer to "what must never change." Be strict: something
that differs in even one ad is not a constant — move it to section 3.

**3. THE CHANGE SURFACE — what varies, element by element**

One table:

`Element | IMAGE 1 | IMAGE 2 | IMAGE 3 | Axis`

One row per element that differs. Give the actual value in each cell, not a
label — the real hex, the real words, the real percentage. `Axis` names the
dimension the variation moves on, using one of these and no others:

`aspect ratio` · `headline wording` · `copy hierarchy` · `typography` ·
`color system` · `image concept` · `crop` · `offer presence` ·
`proof mechanism` · `CTA`

If a difference does not fit one of those axes, add a new axis name and mark
it `(new axis)` so it gets reviewed rather than absorbed silently.

**4. WHAT THE CROP COSTS**

Where two ads are the same execution at different aspect ratios, list exactly
what the tighter crop loses and what it gains: every element cropped out,
every element that changed size relative to frame, and every element that
moved zone. Then state what the tighter version can no longer prove that the
wider version could. If no two ads in the set share an execution, write
"no shared execution in this set" and skip.

**5. THE UNTESTED SURFACE**

Given what varies across this set, name what has NOT been varied — the
elements that are identical in all three and therefore carry no read. This is
the list of next tests. For each: name the element, state its single current
value, and state what a variation of it would isolate. Do not propose specific
new creative; name the element and what varying it would answer.

**6. THE SET'S ELEMENT REGISTRY**

The reusable parts, across the whole set: every bar, badge, highlight box,
arrow, rule, and type style, with its canonical name, its size as a
percentage of frame, its color, and which images use it. Mark each one
`shared` (appears in more than one ad) or `unique to IMAGE n`. A designer
should be able to build one template file from this section and produce every
ad in the set from it.
