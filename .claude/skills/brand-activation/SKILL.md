# Brand activation

Find the gaps. Activate only those. A brand that already works skips what already works.

## Steps

1. Ask what the business is, what is working and what is not. Read its website and its brand folder if they exist.
2. Mark every row below with one state:
   - **Done:** it exists and works. Skip it.
   - **Draft:** it exists but is unconfirmed.
   - **Activate:** it is needed now.
   - **Check:** the owner has to answer.
   - **Later:** it waits on something above it.
   - **Skip:** this business does not need it.
3. Never mark Done from a guess. Use the owner's word or something you read.
4. Save the result as `brands/<brand>/activation.md`, with the state and a one-line reason for each row.
5. Work the first row marked Activate. Run `brands/_TEMPLATE/ONBOARDING.md` for anything in Foundation.

## New or running

- **New product, offer or brand:** Foundation comes first. Everything after it stays Later until product facts, offer and claims are confirmed.
- **Running business:** assume nothing. Confirm Foundation in a few questions, then go to the actual gap.
