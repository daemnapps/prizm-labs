# Consistency

Bound as `{consistency}`.

Decide once, on paper, then every shot copies the paper. Animation studios work this way, and it applies to every generated video.

| Paper | What it locks |
|---|---|
| Model sheet | One locked reference per character, attached to every shot |
| Style line | One written look, pasted word for word into every shot |
| Look test | One approved test frame before a run |
| Color plan | Palette per scene, set up front |
| Set sheet | One locked version of each location |
| Boards | Start pictures approved before motion |

These are defaults. The swipe's own read wins over a default, and the video rulings win over this slice.
