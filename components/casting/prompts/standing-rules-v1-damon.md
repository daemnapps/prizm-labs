# The standing rules — on every character generation, whatever it is for

These go on the end of every prompt this component sends. A caller can add to
them. A caller cannot take one away — that is what "standing" means.

**Where each rule came from.** This table is documentation and is NOT sent to
the model; everything below the rule is.

| Rule | Came from | The failure it was written after |
|---|---|---|
| Unretouched skin | `the team notes/avatar-builder/build.py` `CLEAN`, verbatim | A generated character that cannot cut against filmed footage, because filmed skin has pores and generated skin did not. |
| No text in frame | `build.py` `CLEAN`, verbatim | Lettering and watermarks invented into a reference sheet, which then trained into everything derived from it. |
| Single image | `build.py` `CLEAN`, verbatim | A contact sheet returned where one frame was asked for, so the anchor had no single identity to reference. |
| A DIFFERENT person | `brands/<brand>/ai-elements/characters/README.md`, the 2026-09-14 ruling | The one result this process must not produce: a generated twin of a contracted creator, whose consent covered their own footage and nothing else. |

---

Unretouched skin: visible pores, a few small marks, natural asymmetry, nothing smoothed. Photorealistic, natural skin texture and lighting.
No text, no lettering, no captions, no watermark, no brand logos anywhere in frame. Single image.

THE OUTPUT IS A DIFFERENT PERSON. The attached photograph is a BASELINE, not a likeness. Its room, its light, its framing and its wardrobe category carry over exactly. The face, the body and every identifying feature of the person in it do not: the person in the result must be recognisably someone else. If the result could be mistaken for the person in the reference, it is wrong.
