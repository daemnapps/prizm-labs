The four components

Four folders. Yours is now marketing-chain-checks

marketing-chain-checks/

the owner

Checks the ads and briefs our chains make, stops bad work moving on, and checks the chains themselves. Was called quality-checks until 2 Oct.

Has
The hold every chain uses (5 gates: inputs · elements · copy · media · delivery) · price, unfilled-slot and copy checks · the creative review after every stage · the QC log in every run · the viewer check (new today)
Called by
Every the owner chain: video teardown, copywriter, email, image, casting, calendar, intake, meta upload, video edit, and the lab teardowns
Judges
A machine (Gemini / GPT), plus code
Path
components/quality-checks/ · a stub at the old path forwards old links

qc-checks/

the developer · the definitions curator

Checks finished text and built pages for defects, and files what it finds for a person to rule on.

Has
text_check (live): typos and banned words against a brand's QC dictionary · voice_check (pending): would she say it like this · avatar_walk (pending): clicks through a built funnel as the avatar
Called by
The /qc-check skill and the mini worker. Your chains don't call it.
Judges
Code and a dictionary. Output goes to review for a person.
Path
components/qc-checks/

review/

the developer · the definitions curator

Not a checker. It's the record of a person's verdict: ask, then verdict, then close.

Has
The review record ("RQ-…"), the module that files and reads them, panels on the platform. Its format is frozen.
Called by
/review-request, /review-status, qc-checks when it files findings
Judges
A person (the definitions curator, a lead, you)
Path
components/review/

page-picture-review/

the developer

Numbers every picture slot on a built landing page and records the decision on each one.

Has
Slot numbering, fit, the page's picture decisions (a product's Picture Index runs on it)
Called by
Landing-page work on Brand A
Judges
People, clicking on the page
Path
components/page-picture-review/

Two layers

Checks inside the loop, and checks on the loop

How marketing-chain-checks is organised from 2 Oct.

LayerWhat it checksBuiltNot built yet
1 · Inside the loopEach ad or brief as it moves through a chain. It stops it or sends it back.The hold and its 5 gates · price, unfilled and copy checks · the creative review after every stage · the viewer check after the writing—
2 · On the loopThe chain itself: is it working, and is it current?The QC log: every round filed in the run, and a cause that would come back written up as a change to the chainThe same viewer complaint across briefs turning into a prompt change on its own · the viewer check's calls measured against live Meta results · a check that a chain's prompts and avatar files are the current ones

Other checks on the system, owned by others: /system-review (does a folder follow the workspace rules) and the control room's machine check.

Where the names collide

Same word, different thing

"quality-checks" and "qc-checks" renamed 2 Oct

These were two different components with almost the same name. Yours is now marketing-chain-checks. qc-checks stays the developer's: it checks finished text and pages and files findings for a person. the developer ruled on 30 Sep that the two stay separate. Your component's notes used to say it calls qc-checks. No code ever did, and that line is now gone.
