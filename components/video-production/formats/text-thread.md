# Format · Text thread

**The bank row** — in `bank.json`, `draft` until the owner signs it.

**Shape.** A phone screen recording of one chat. One message is held down at a time, the rest of the chat blurred behind it. The words do all the work; the pictures are the messages. Production format; the script format is named on the run.

| | |
|---|---|
| **Cast** | No face on camera. One person's picture may sit inside a made-up page. Voices only: the victim's voice notes and a short teller. |
| **Places** | None. The phone screen. |
| **Scenes** | One step per message: text, image, voice note, missed call. |
| **Sound** | Voice notes through a phone speaker, a teller's few lines clean, a soft tap on each step. Music only if the swipe has it. |

**What a scene contains.** one message held down on a phone, the chat blurred behind it, the reaction bar above and the menu below

**The beat shape.** The setup in one line → the made-up page → the reactions rising → more pages → silence and missed calls → the panic → the real thing in the same thread → the price fight → the send.

**Stations used.** voice · edit. No cast, still, restyle or motion.

**The references it needs.** The swipe's own screen. The real product photo for any product step. One picture for a made-up page.

**The sections that carry the weight.** Hook, dramatized problem, close. The offer is a fight in the thread, not a card.

**Ledgers that apply.** Claims and offer. No cast or continuity ledger, because no one is on camera.

**Post (edit-time).** All of it, drawn in code by `components/video-edit/thread/`. Voice-note words on screen in capitals, in quotes.

**Gates it adds.** None — `RUN-PROTOCOL.md` carries them.

**The failure this format invites.** Messages too fast to read. The hold comes from the length of the message, never from a flat count.

**The run it was proven on.** `runs/video-edit/Brand A/text-thread-flex-wanted/`, 2026-11-02.

**What still fails.** Not yet proven as a paid ad; ranks come from organic posts.
