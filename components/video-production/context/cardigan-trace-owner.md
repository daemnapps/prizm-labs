# Cardigan Trace

One unsourced line is pasted into every Brand B writing run before the swipe gets a say. Then the system counts its own output as proof.

## The loop

1. Born in the first avatar sheet, with no customer record behind it.
2. Copied into the language bank as her own words, with no name or source.
3. Made the pull quote of the brand position.
4. Pasted into every run: the avatar, bank and position files go in whole, 18 to 24 mentions per run in three clean runs checked.
5. The rule "every hook traces to a verbatim" sends the writer to the bank for a vivid line.
6. Output returns as evidence: the "six creators" claim in the strategy file cites our own hook cards, and the position file calls the angle "receipted six times".

## What the language layer is doing

It is plugged in and rotates fresh lines each run. The cardigan is not in it. Each prompt carries about 85K letters of fixed files against about 6K of rotating rows.

In the 1,442 Brand B rows: sleeves 0, granddaughter 0, shorts or swimsuit 0, leg makeup 1, first person with a life word about 64 (rough word match, many off topic). Most rows are support tickets and fan comments. There is no tag for a lived experience, so a writing step cannot ask for one.

## What's fixed now

- Fixed files as the chains read them: stock moments are out for both brands; positioning, benefits and rules stay.
- Moments per avatar: Brand B spot-hider 47, dry-skin 18; Brand A glow-up 43, face-back 34, fed-up-king 33, gift-buyer 8.
