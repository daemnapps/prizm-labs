One row of the brief. This is how most runs get chopped up.

Closest to what you want. Later rules cut across it: each line its own read, and clips grouped up to the 15 second limit.

What this points to

  1. Add the routing step. After writing, the brief names its production line, and only that line's stations run.
  2. Pick one meaning of scene. A scene is one continuous moment with all its elements, built in one generation as far as the model allows.
  3. Build the Movie line first. It's the biggest gap: elements, then full-scene prompts, on Seedance's longest length.
  4. Add cutscene as its own thing, separate from B-roll, from the brief onward.
  5. Move the code tools into production and give them one shared base. That card is already up.
  6. New format, new line. When a swipe doesn't fit, build a line for it from tools we already have, and reuse them when they fit.
