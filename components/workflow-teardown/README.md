# workflow-teardown


Capture another platform's generative workflow word for word, take it apart, rebuild it as our own recipe, and name the
cheapest model for every step. Owner: the owner. See `CLAUDE.md`.

- `sources/higgsfield/` — Higgsfield's workflows, recipes, commands and Drama Ads catalog, verbatim (`SOURCES.md`).
- `breakdowns/` — one page per workflow.
- `recipes/` — our versions (`README.md` has the rules).
- `tools/harvest.py` — capture from a session's raw results. `tools/build.py` — `index.json` for the Studio page.
