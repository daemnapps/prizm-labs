# Switch list (inside promo-pack)

Say: **"where does the old offer still live"**.

Search every place the outgoing offer's words and codes can sit: the store theme, each funnel, the email flows,
the month's written emails and texts, ad copy and briefs, the pop-ups, the offer and language banks. List each
place by file with the line to change.

The pack already flags written emails and texts that carry a retired or funnel-only line (the email and sms
hand-offs, `written.flags`). The rest is this list, saved as `runs/promo-pack/<brand>/<moment>/switch-list.md`
for the page-builder and the retention-strategist.
