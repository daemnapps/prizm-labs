# The sections — a vocabulary, not a sequence

Bound as `{sections}`. Source: the doctrine component; refs are line pointers into the book, for verification only.

A vocabulary, not a sequence. The sections in the list name what a part of an asset is DOING. Any ad carries any subset, in any order, with repeats; the framework the source follows is read off the asset and named, never imposed. The point is that every part is labelled for what it does, so a brief can be fleshed out and the writing can get creative systematically — knowing which job each beat is holding. [L667-972] [L462-473]

**Awareness decides the sections.** The awareness level decides which sections an asset needs at all. Most-aware skips straight to offer and call to action; product-aware works the gap between knowing and wanting; solution-aware needs the unique mechanism and proof; problem-aware needs the problem named and the root cause; unaware opens on identification before any problem is named. A section the level does not call for is dead time.

The list is the list — never one it does not carry, never a renamed one. Each names the techniques that build it and the levels that call for it.

## How the common frameworks read into the vocabulary

Common copy frameworks read into the same vocabulary — so a swiped asset's own shape is named in one line and every part still carries a section label. Add a row only when a real asset follows a shape none of these covers; describe it plainly and flag it.

| Framework the asset follows | Its parts, as section ids |
|---|---|
| PAS (problem · agitate · solve) | `hook` → `problem` → `agitation` → `solution` → `unique-mechanism` → `proof` → `product` → `offer` → `objections` → `call-to-action` |
| AIDA (attention · interest · desire · action) | `hook` → `identification` → `problem` → `transformation` → `proof` → `product` → `offer` → `urgency` → `call-to-action` |
| BAB (before · after · bridge) | `hook` → `problem` → `transformation` → `unique-mechanism` → `proof` → `product` → `offer` → `call-to-action` |
| Story / testimonial (life · tried · found · now) | `hook` → `identification` → `problem` → `failed-solutions` → `root-cause` → `product` → `unique-mechanism` → `proof` → `transformation` → `objections` → `offer` → `call-to-action` |
| Mechanism-led (the new way) | `hook` → `problem` → `root-cause` → `unique-mechanism` → `proof` → `solution` → `product` → `objections` → `offer` → `call-to-action` |
| Us-vs-them / comparison | `hook` → `problem` → `failed-solutions` → `root-cause` → `unique-mechanism` → `proof` → `product` → `objections` → `offer` → `call-to-action` |
| Direct offer (most-aware) | `hook` → `offer` → `proof` → `urgency` → `call-to-action` |
| Identification-only (unaware) | `hook` → `identification` → `problem` → `transformation` → `solution` → `product` → `call-to-action` |
