# The cover's word band: the headline is set afterwards, so the picture keeps the band clear of faces

Added to the standing rules of a cover whose words are set by the tool's words step. The picture model paints no
words; the headline is set over the band by `image_production/words.py` `set_headline`, the same face, weight, size
and band on every version of the ad. Nothing is ever set on a face or lips, so the picture keeps them out of the band.

Slot: `{band}` is where the band is, in plain words.

---

NO WORDS ARE DRAWN IN THIS PICTURE. No words, letters, numbers, captions or logos anywhere. The headline is set
afterwards across {band}. Compose the picture so that no face, no lips, no eyes and no hands are inside that band:
it holds only background, hair, a shoulder, a wall, sky or an out-of-focus part of the scene, with enough even tone
that large type reads on it.
