Acquisition tracking standard

One spec for every funnel, both brands. Every step sends the same event to Meta, GA4 and Clarity, and every event carries the ad that brought the visitor in. The pull request below makes this brand's funnel meet it.

Every Meta ad carries these URL tags

The ad name rides in utm_content and the ad id in sub1, which the store keeps on every cart and order. The uploader now puts these on every ad it makes. Email links get the same shape: utm_source=klaviyo&utm_medium=email&utm_campaign=<campaign or flow>&utm_content=<message>.

Every event also carries ad_name, brief, batch, campaign, ad set, ad id, funnel, page and step, plus an event id. Purchase uses <store>-<order>, the same id the store's Meta app sends from the server, so Meta counts it once. Upsells go as UpsellTake with value, never as a second Purchase.
