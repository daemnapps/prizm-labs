# Asking a question

There is no group chat, no support email and no DMs.

Use the question form on **[daemn.co](https://daemn.co)** — it writes the
message for you and opens it in your own email. Say what you were trying to
do and what actually happened; that is usually enough.

Or open an issue on this repo, which is public and searchable, so the answer
helps whoever hits it next.

**Never paste an API key, a password or a customer's details** into either.
If you already have, rotate the key at the provider — deleting the message
does not un-send it.
