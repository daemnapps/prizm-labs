# Questions

Every question asked through the form on [daemn.co](https://daemn.co) lands
here as a file. Nothing is stored anywhere else — this folder is the record.

| | |
|---|---|
| `open/` | asked, not answered yet |
| `answered/` | answered — the answer is at the bottom of the file |

Keys and email addresses are stripped automatically before anything is
written, but don't paste them in the first place.

Nobody needs an account to ask. If you'd rather use GitHub, open an issue
instead — same queue, same answers.
